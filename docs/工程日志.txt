液态玻璃性能工程日志
日期：2026-10-21（Asia/Shanghai）

验收约束
- 保留连续折射；不允许滚动时关效果、降更新频率或切成毛玻璃。
- 不改用户保存的 between-glass-v1 外观参数。
- 旧版保存在 baseline-svg.html，入口 index.html 路径保持不变。
- 测量数字必须注明环境、负载与限制；rAF 频率不等于屏幕实际呈现帧率。

01 / 代码审查与基线归档
工作：复查滤镜链、位移图缓存、滚动输入监听、展开/收起动画。
结果：滚动不调用位移图重建；动画用 transform；没有常驻 JS 渲染循环。
判断：背景位移滤镜/模糊/光栅化/合成是待测对象，尚无 GPU trace，不能宣称已定位到某一阶段。
保留：SVG 原版完整归档。
放弃：滚动时暂缓折射（视觉穿帮）；Worker 重算位移图作为滚动优化主线（并非逐帧工作）。

02 / 实验计划
路线 A：保留原生 SVG，记录隐藏/展开与滚动表现，检查事件监听等次要开销。
路线 B：浏览器原生 foreignObject 光栅化静态底板，缓存纹理；WebGL2 只更新采样位置。
视觉要求：沿用原位移图的 8-bit 通道与折射尺度，保留 DOM 个人信息、CSS 高光、阴影与底色。
风险：foreignObject 的 origin-clean、离线支持、文字光栅化一致性、原生滚动与 rAF 的同步。
验证方式：独立实验页、实际 UI 操作、截图、参数极值测试、受控滚动测量；不声称能通过现有浏览器接口直接取得完整 DevTools GPU trace。
状态：进行中。
03 / 原型实现：采用原生 foreignObject 将底板及其已计算样式光栅化，保留 box-shadow；以同一份 8-bit 位移图驱动 WebGL2。实现折射后两遍可分离高斯模糊，再做饱和度；没有改成先模糊底板再折射，避免改变边缘算法。滚动不截图、不上传整张纹理。当前版本仍在独立 work/candidate.html 验证，未替换入口。
04 / 测试装置校正：发现实验室按钮会触发原页面的点击外部收起，导致第一轮标记展开但实际隐藏，第一轮数据全部作废。为实验室控制区阻止点击冒泡，并在结果中增加 actualOpen 交叉校验。另发现新标签页默认 DPR=2，而 viewport override 为 DPR=1，后续必须逐页显式记录和统一。
05 / 视觉核验：原生 foreignObject 成功保留底板插画与 box-shadow。全页截图会临时改变布局宽度，造成假偏移，改用固定视口截图。排除实验室覆盖区后，首轮视口纹理对照平均 RGB 绝对差约0.97/255，约2.92%像素最大通道差超过8；不是逐像素完全一致，需进一步比较经过玻璃后的结果。
06 / 缓存与测量：首轮有效 GPU 受控滚动6秒，captureCount=3→3、textureUploads=4→4，验证滚动没有重新捕获或上传背景；期间527次实际绘制。rAF P95=8.4ms，不能据此声称真实呈现120fps。原版同场 rAF 也接近该水平。新增异步 GPU timer query；若设备不支持，明确记为不可用。
07 / GPU 计时：使用 EXT_disjoint_timer_query_webgl2 异步查询，不用 CPU 提交时间冒充 GPU 时间。1365×950、DPR1、默认参数的6秒测试，31个有效查询样本：GPU中位0.213ms、P95 1.577ms；captureCount 1→1、textureUploads 2→2。此时间仅含自有GPU绘制，不含浏览器最终合成和屏幕呈现。
08 / 视觉路线修正：强折射3×、透明100%、模糊0、边缘100px时发现原版最外沿存在镜像输入采样；直接读取面板外真实背景不等价，因此放弃最初的直接采样，改用镜像边界。边缘结构已复现。默认参数旧/新玻璃未遮挡区域平均通道差约0.29/255，强折射零模糊最外沿仍有抗锯齿/亚像素差异，保留原版引擎用于随时对照。
09 / 极值与缓存：验证 blur=24px、radius=0、saturation=200%、refraction=3×、transparency=100%组合，无控制台错误；恢复测试用默认值，未触碰用户 file URL 下的存储。模糊核已缓存，避免逐帧重新分配数组；纹理首帧绘制后再切换，避免空白首帧。
10 / DPR2：1280×720视口、DPR2、1500×804玻璃画布、默认参数，6秒受控滚动，GPU有效样本36：中位0.697ms、P95 1.148ms；捕获2→2、纹理上传5→5，rAF无>12ms样本。纹理重建156ms发生在尺寸切换后的准备阶段，未发生在滚动期间。
11 / 输入链路：移除 document 上的非 passive touchmove。底部84px手势区、按钮和横条改为局部 pointer 事件及 touch-action:none，正常页面触摸滚动不再依赖全局可取消监听。
12 / 参数与回退：参数JSON导出再读取，与导入样本完全一致；无效JSON拒绝导入且保留原值。模拟 WebGL 上下文丢失后，实际滤镜恢复 url(#liquid-refraction) blur(1.5px) saturate(1.1)，仍是完整折射，不是毛玻璃。参数存储键及默认外观未变。
13 / 窄屏验收：390×844无横向溢出，底部任意区域上拉展开、横条下滑收起、Enter展开、Esc关闭均通过；滚轮后仍为webgl2。低高度窗口将滚动限制在资料内容层，玻璃及关闭横条保持固定。
14 / 路线取舍：采用原生光栅化缓存底板+WebGL2位移+折射后可分离高斯模糊，保留SVG对照与故障回退。不采用每帧DOM截图、html2canvas重建插画、滚动时关折射、常驻空转RAF、盲加will-change。边缘分区SVG尚未实现/计时：考虑多次背景抓取和接缝风险，GPU原型已满足自有绘制预算，因此本轮不再增加该复杂路线。HTML-in-Canvas仍不作为必需的实验依赖。
15 / 最终构建测量：DPR2、默认参数、6秒受控滚动，renderModes 始终只有 webgl2；捕获1→1、上传2→2，实际绘制50→683。GPU累计35样本（包含少量预热）：中位0.81ms、P95 2.249ms；rAF P95 8.4ms。没有取得浏览器最终呈现轨迹，不将这些数字等同显示器120fps。
16 / 交付限制：静态纹理存在字体抗锯齿和亚像素差异；强折射零模糊不是逐像素等价。真实合成线程和主线程在CPU压力下的单帧同步未获得显示级轨迹验证。file: URL 被浏览器工具安全策略禁止，未绕过；本轮自动化验证为本地HTTP，离线代码保留SVG故障路径。独立8秒空闲观察绘制计数87→87，证实静止时不空转；早先manual轮滚动发生在预热阶段，不作为原生滚轮帧率数据引用。
17 / 最终静态核验：HTML ID无重复；无外部运行资源；原参数存储键保持；无滚动降级逻辑；无全局touchmove阻塞监听；最终有效测量确认actualOpen=true、renderModes仅webgl2、绘制增加而捕获/上传不增加。交付入口、原版备份、实验室、说明、原始测量数据已整理。

18 / 选中状态缺失：用户发现玻璃下不显示文字选中。根因是 foreignObject 页面副本只序列化 DOM/样式，原生 Selection 绘制状态不在其中，MutationObserver 也无法覆盖此状态。此前将静态缓存作为正式默认的结论撤回；GPU计时只代表自有绘制成本，不是动态页面正确性证据。
19 / 路线修正：正式默认恢复实际页面的 SVG backdrop-filter，全程保留折射，不在滚动或选中时临时切换效果。WebGL 缓存保留为明确标注缺失选中/悬停/动画状态的实验选项；默认不创建WebGL或捕获底板。渲染偏好使用v2独立键，使旧版auto不再自动启用缓存；between-glass-v1外观存储、初版模式及已有版本标签保持原样。
20 / 放弃：不做selectionchange后重新截图（原生高亮本来就不在序列化内容中），不伪造选区覆盖层（会遗漏跨行/排版/其他浏览器绘制状态），不采用滚动时关闭折射。后续性能优化必须在真实动态背景和持续折射条件下验证；本修复不宣称解决120Hz呈现瓶颈。
21 / 修复验收：本地HTTP实测底板全选后键盘展开，高亮参与原生折射/模糊（previews/live-selection.png）。默认engine=svg、renderMode=refraction、gpu-glass数量0；滚动仍为完整SVG滤镜。实验webgl2可用，切回实时及收起通过，控制台无错误/警告。脚本语法检查通过，原入口与仓库终版逐字节一致。实际呈现帧率尚未验证。
